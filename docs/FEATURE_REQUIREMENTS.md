## 1. 项目概述

agentGui 是一个基于 Swift 6.0 + SwiftUI 的 macOS 原生 Claude 客户端，通过 Anthropic 官方 API 与 Claude 对话。项目定位为「Claude Code 的轻量级 GUI 客户端」，专注于提供流畅的 AI 对话体验和强大的工具调用能力。

### 1.1 当前架构概览

```
agentGui/
├── Models/              # SwiftData 数据模型
│   ├── Session         # 会话
│   ├── Message         # 消息
│   ├── ToolCall        # 工具调用记录
│   ├── AgentRound      # Agentic Loop 轮次
│   └── AppSettings     # 应用设置
├── Views/              # SwiftUI 视图
│   ├── ChatView        # 聊天界面
│   ├── SessionListView # 会话列表
│   └── AgentStepTimelineView # 工具调用时间线
├── Services/           # 业务逻辑
│   ├── ClaudeService+AgenticLoop # Agentic Loop 实现
│   ├── ClaudeService+ToolDispatch # 工具调度
│   └── BashSession     # Shell 会话管理
└── Repositories/       # 数据访问层
```

## 2. 用户交互增强需求

### 2.1 消息操作 [优先级: P0]

**现状**: 用户发送消息后无法修改、删除或重新生成

**需求**:
- [ ] **消息编辑**: 允许用户编辑已发送的消息，编辑后自动重新发送
- [ ] **消息删除**: 删除单条消息或删除该消息后的所有对话
- [ ] **消息重试**: 当网络错误或 API 失败时，提供「重新发送」按钮
- [ ] **消息复制**: 一键复制消息内容（支持富文本/Markdown 格式）

**交互设计**:
```
消息气泡右键菜单 / 悬浮工具栏:
┌─────────────────────────┐
│ ✏️ 编辑   📋 复制        │
│ 🔄 重新生成   🗑️ 删除     │
└─────────────────────────┘
```

---

### 2.2 会话管理 [优先级: P0]

**现状**: 新会话标题固定为「新对话」，搜索和导出功能缺失

**需求**:
- [ ] **自动标题生成**: 使用 Claude API 基于首条对话生成会话标题
- [ ] **会话重命名**: 允许用户手动编辑会话标题
- [ ] **会话搜索**: 全文搜索所有会话内容
- [ ] **会话导出**: 导出为 Markdown、JSON 或 PDF 格式
- [ ] **会话分组**: 使用文件夹或标签组织会话
- [ ] **置顶会话**: 将重要会话置顶显示

---

### 2.3 输入增强 [优先级: P1]

**现状**: 仅支持纯文本输入，缺少快捷输入方式

**需求**:
- [ ] **提示词模板**: 保存常用提示词为模板，一键插入
- [ ] **多模态输入**: 支持拖拽图片、PDF 文件到输入框
- [ ] **语音输入**: 集成 macOS 语音识别，支持语音转文字
- [ ] **代码块输入**: 支持在输入框中插入代码块（带语法高亮）
- [ ] **@ 引用**: 支持 `@文件` 或 `@会话` 引用功能

**提示词模板设计**:
```swift
struct PromptTemplate: Identifiable, Codable {
    var id: UUID
    var title: String
    var content: String
    var category: TemplateCategory // codeReview, writing, analysis, etc.
    var shortcut: String? // Cmd+1, Cmd+2...
}
```

### 2.4 响应展示增强 [优先级: P1]

**现状**: 代码块无语法高亮，缺少一键复制按钮

**需求**:

- [ ] **代码一键复制**: 每个代码块右上角显示复制按钮
- [ ] **表格渲染**: 支持 Markdown 表格的美化展示
- [ ] **数学公式渲染**: 支持 LaTeX/KaTeX 数学公式
- [ ] **Mermaid 图表**: 支持渲染流程图、序列图

### 2.5 快捷键与效率 [优先级: P2]

**需求**:
- [ ] **全局快捷键**: 唤起应用、新建会话、聚焦输入框
- [ ] **导航快捷键**: 上下切换消息、左右切换会话

## 3. Agent Loop 设计增强需求

### 3.1 安全性增强 [优先级: P0]

**现状**: Bash 工具和文件操作无确认机制，存在安全风险

**需求**:
- [ ] **危险操作确认**: 删除文件、执行危险命令前弹窗确认
- [ ] **权限白名单**: 限制可访问的目录范围
- [ ] **命令黑名单**: 禁止执行 `rm -rf`、`dd` 等危险命令
- [ ] **沙盒模式**: 提供只读模式，禁用写入操作

**权限模型设计**:
```swift
enum PermissionLevel {
    case readOnly        // 只读：仅查看文件
    case restricted      // 受限：仅允许指定目录
    case fullAccess      // 完全：访问所有文件
    case sandbox         // 沙盒：虚拟文件系统
}
```

---

### 3.2 执行控制 [优先级: P0]

**现状**: Agentic Loop 启动后无法中断

**需求**:
- [ ] **停止按钮**: 执行过程中显示「停止」按钮，点击后中断当前轮次
- [ ] **暂停/恢复**: 支持 Agentic Loop 的暂停与恢复
- [ ] **单步执行**: 调试模式下，每轮工具调用后等待用户确认再继续
- [ ] **执行超时**: 设置单轮和总执行超时时间

---

### 3.3 并行执行 [优先级: P1]

**现状**: 工具串行执行，效率较低

**需求**:
- [ ] **并行工具调用**: 当工具之间无依赖时，并行执行多个工具
- [ ] **依赖分析**: 自动分析工具调用之间的依赖关系
- [ ] **并发控制**: 设置最大并发工具数量

**并行执行示例**:
```
用户: "分析 src/ 和 tests/ 目录下的所有 Swift 文件"

并行执行:
├─ Read: src/Models/*.swift
├─ Read: src/Views/*.swift
└─ Read: tests/*.swift

然后汇总分析
```

---

### 3.4 工具生态 [优先级: P1]

**现状**: 仅内置文本编辑器和 Bash 工具

**需求**:
- [ ] **MCP 服务器集成**: 支持 Model Context Protocol，接入外部工具
- [ ] **自定义工具**: 允许用户编写自定义工具脚本
- [ ] **工具市场**: 预设常用工具包（HTTP 请求、数据库查询等）
- [ ] **工具调试界面**: 可视化查看工具输入输出

**MCP 集成设计**:
```swift
struct MCPServer {
    var name: String
    var command: String // 启动命令，如 "npx -y @modelcontextprotocol/server-example"
    var args: [String]
    var enabledTools: [String] // 启用的工具列表
}
```

---

### 3.5 可观测性 [优先级: P2]

**现状**: 执行过程仅显示最终结果

**需求**:
- [ ] **详细日志面板**: 显示每轮的请求/响应详情
- [ ] **Token 统计**: 实时显示 Token 消耗和预估费用
- [ ] **执行时间线**: 可视化展示各阶段耗时
- [ ] **错误诊断**: 失败时提供详细的错误信息和解决建议

## 4. 创新功能需求

### 4.1 任务管理 [优先级: P1]

**描述**: 将 AI 对话与任务管理结合，让 Claude 成为任务助手

**需求**:
- [ ] **任务提取**: 从对话中自动提取任务项
- [ ] **任务看板**: 类似 Trello 的看板视图（待办/进行中/已完成）
- [ ] **任务关联**: 任务与消息关联，点击任务跳转到相关对话
- [ ] **任务提醒**: 基于任务内容设置提醒

**数据模型**:
```swift
@Model
class Task {
    var id: UUID
    var title: String
    var status: TaskStatus // todo, inProgress, done
    var priority: TaskPriority
    var relatedMessage: Message?
    var dueDate: Date?
    var tags: [String]
}
```

---

### 4.2 知识库 [优先级: P1]

**描述**: 构建个人知识库，让 Claude 基于知识库回答

**需求**:
- [ ] **文档导入**: 支持 Markdown、PDF、网页抓取
- [ ] **向量化存储**: 使用 Embedding API 构建向量索引
- [ ] **语义检索**: RAG (Retrieval-Augmented Generation)
- [ ] **知识库关联**: 为不同会话绑定不同知识库

---

### 4.3 工作流自动化 [优先级: P2]

**描述**: 将常用操作序列化为工作流，一键执行

**需求**:
- [ ] **工作流编辑器**: 可视化编辑工具调用序列
- [ ] **预设工作流**: 代码审查、文档生成、测试执行等
- [ ] **条件分支**: 支持根据结果执行不同分支
- [ ] **循环执行**: 支持批量处理

---

### 4.4 多模态交互 [优先级: P2]

**需求**:
- [ ] **图片分析**: 利用 Claude Vision 分析截图
- [ ] **屏幕录制**: 录屏并发送给 Claude 分析
- [ ] **语音对话**: 实时语音转文字 + 文字转语音
- [ ] **画布协作**: 支持在白板上与 Claude 协作绘图

---

### 4.5 团队协作 [优先级: P3]

**需求**:
- [ ] **会话分享**: 生成分享链接，类似 Claude.ai 的分享功能
- [ ] **协作编辑**: 多人同时编辑同一个会话
- [ ] **评论系统**: 在消息上添加评论
- [ ] **版本历史**: 追踪会话的修改历史

## 5. 性能与体验优化
