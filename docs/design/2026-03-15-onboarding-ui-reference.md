# 首开引导窗口视觉参考

日期：2026-03-15

## 参考来源

1. Apple Human Interface Guidelines `Designing for macOS`
2. Apple WWDC25 `Get to know the new design system`
3. Raycast 官网公开产品页
4. Linear 官网公开产品页
5. Arc Help Center `Getting Started`

## 提取到的方向

### 1. Apple / macOS 侧

1. 利用大屏展示更多信息，减少不必要的嵌套和模态层级。
2. 新设计系统强调更动态、和谐、与内容连续的结构关系。
3. 材料和层级应轻，不应把主内容压成厚重卡片堆叠。
4. 桌面应用需要支持键盘流和窗口级独立工作方式。

### 2. Raycast 侧

1. Hero 区域很宽，视觉重心先给“核心价值”而不是表单本身。
2. 高密度但不杂乱，配合清晰的功能分区和简短文案。
3. 玻璃与光晕更多是氛围，而不是主结构。

### 3. Linear 侧

1. 整体更 calm and focused，强调稳定结构与低噪声信息面。
2. 用宽布局、模块化区块和轻描边来建立秩序，而不是靠强对比堆元素。
3. 文案短、层级清楚、信息块之间留白充分。

### 4. Arc 侧

1. Getting Started 独立成资源入口，而不是混进主工作流页面。
2. 上手内容按主题分组，强调“先学基础，再进入主界面”。

## 对 agentGui onboarding 的落地要求

1. 引导窗口应保持独立 scene，不回退到聊天空态卡片。
2. 使用双栏结构：左侧步骤轨道，右侧当前步骤 hero 面板。
3. 背景光效存在，但控制在氛围层，不盖过文字与按钮层级。
4. 主文案控制在一句价值说明 + 一句动作说明，避免长段解释。
5. 视觉风格以冷静、现代、桌面生产力工具为方向，而不是营销页式夸张视觉。
