# 功能规范 - 工作空间与会话管理

## 规范 1：最近打开的工作空间

### 需求
支持记录最近打开的 10 个工作空间。

### 实现要点
- 使用 UserDefaults 或文件持久化存储工作空间路径
- 保持最近 10 条记录，超过时移除最旧的记录
- 打开工作空间时更新记录列表
- 在 UI 中提供快速访问入口（可选）

### 数据结构建议
```swift
struct WorkspaceHistoryItem: Codable {
    let path: String
    let lastOpened: Date
    let workspaceName: String
}
```

---

## 规范 2：会话列表大小限制

### 需求
会话列表要控制最大值，最多记录 25 个会话。

### 实现要点
- 新增会话时，检查当前会话数量
- 超过 25 个时，删除最旧的会话
- 基于创建时间或最后访问时间判断会话新旧
- 考虑用户手动标记的收藏会话不被清理（可选）

### 清理策略建议
- 按创建时间排序，保留最新的 25 个
- 或按最后访问时间排序，保留最近活跃的 25 个
